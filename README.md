# SoleX — High-Performance Sneaker E-Commerce Platform

SoleX is a production-quality, responsive e-commerce web application for premium athletic and lifestyle footwear built with **Next.js 14**, **React 18**, **TypeScript**, and **Tailwind CSS**.

---

## ✨ Features

- **240-Frame Interactive Hero Animation**: Smooth frame-by-frame canvas scroll animation showcasing the flagship sneaker architecture.
- **Dynamic 4-Angle Colorway Switching**: Each shoe variant features 4 studio product photography angles (Profile, Quarter, Toe Box & Laces, Heel & Air Cushioning) that update live when color swatches are selected.
- **Shop Catalog & Smart Pagination**: Filter by category, price, colorway, size, rating, and sort order with smart 9-per-page ellipsis pagination (`1 ... 4 5 6 ... last`).
- **Interactive Bag & Persistent Wishlist**: Real-time sliding cart drawer, free shipping progress calculator, size-aware item grouping, and local persistence.
- **Simulated Checkout & Order Tracking**: Realistic multi-step checkout with Cash on Delivery / Card options, immediate order confirmation, and order history dashboard.
- **Production Hardened**: Custom HTTP security headers, framework fingerprint suppression (`poweredByHeader: false`), dynamic `sitemap.xml`, and `robots.txt` ready for Vercel deployment.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animation**: Framer Motion
- **Icons**: Lucide React
- **Image Processing**: Sharp

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/saimdev68-cmd/SoleX.git
cd SoleX
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Build for production
```bash
npm run build
npm run start
```
